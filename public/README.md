# Files required here before deploying

Nothing in this folder is generated by the app — these are static
assets referenced by URL, and the app will 404 or show a broken icon
without them:

## resume.pdf (required)

`lib/site-config.ts` → `links.resume` points to `/resume.pdf`. The
"Download Resume" button on the homepage, nav bar, and `/resume` page
all link here. **Add your actual resume PDF at `public/resume.pdf`**
(or update `links.resume` in `site-config.ts` to point elsewhere —
e.g. a Supabase Storage URL, if you'd rather manage it from `/admin`
instead of redeploying every time it changes).

## Favicon (recommended, not required)

No favicon was ever added. Add one of:
- `app/icon.png` (or `.ico`/`.svg`) — Next.js picks this up
  automatically via its file-based metadata convention, no code
  changes needed.
- `public/favicon.ico` — the traditional path, also picked up
  automatically.

Without either, browsers show a generic default icon — not broken,
just unpolished.
